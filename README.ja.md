# findhydrant_kurashikicity

岡山県倉敷市のオープンデータを活用し、消火栓やその他の消防水利（防火水槽など）を検索するウェブアプリケーションです。

## デモ

**https://code4fukui.github.io/findhydrant_kurashikicity/**

![消火栓のアイコンが配置された倉敷市の地図を表示する findhydrant_kurashikicity アプリのスクリーンショット。1つの消火栓のポップアップが開き、詳細情報が表示されています。](ss.jpg)

## 機能

-   **地図ベースの可視化**: インタラクティブな地図上に消火栓や防火水槽の位置を表示します。
-   **現在地取得**: ユーザーの現在地を自動的に検出し、地図の中心に合わせて近くの水源を検索します。
-   **最寄り検索**: 現在地に最も近い消火栓を即座に計算し、ハイライト表示します。
-   **詳細情報**: 任意のアイコンをクリックすると、水源の種類、住所、口径などの詳細情報が表示されます。
-   **動的なアイコン**: 消火栓、防火水槽、その他の水源を区別するために異なるアイコンを使用します。
-   **多言語対応**: ブラウザの言語設定に合わせてインターフェースが自動的に適応します（日本語、英語など）。

## 使い方

1.  [デモアプリ](https://code4fukui.github.io/findhydrant_kurashikicity/)を開きます。
2.  位置情報へのアクセスを求められたら、許可します。
3.  地図上に近くの消火栓が表示されます。
4.  「find nearest（最寄りを検索）」ボタンをクリックすると、最も近い消火栓に移動します。
5.  地図上の任意の消火栓アイコンをクリックすると、詳細情報が表示されます。

## データソース

このアプリケーションは、倉敷市が提供する「消防水利（消火栓、防火水そう等）」データセットを元にしたCSVファイルを同梱して使用しています。

-   **データ提供元**: [おかやまオープンデータカタログ](https://www.okayama-opendata.jp/resources/14754)
-   **ローカルデータファイル**: [`332020_fire_hydrant_202404_standard.csv`](332020_fire_hydrant_202404_standard.csv)

データはアプリケーション内のローカルファイルから直接読み込まれて処理されるため、消火栓データの取得に外部API通信は行われません。
